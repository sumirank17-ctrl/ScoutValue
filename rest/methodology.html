Methodology

How the transfer value model works

This project estimates a player’s market value from a blend of baseline profile data, performance signals, and market context. The model is designed to be transparent and analyst-friendly rather than a black-box prediction.

Core approach

  • Each player starts from a baseline market value derived from a static transfer-market style dataset.
  • Age, contract length, and position profile influence the current valuation curve in a realistic way.
  • Current form, minutes played, output volume, and demand adjust the value upward or downward.
  • Market momentum captures whether a player’s profile is rising faster than the broader market.
  • The final output is a projected transfer value with a plausible range rather than a definitive fee.

Valuation logic

The model combines a player’s current profile with analyst-adjusted market pressure:

projected value = base value × contract factor × form factor × demand factor × momentum factor × age profile

In a more advanced production version, this logic is typically implemented as a gradient-boosted tree model trained on historical transfer outcomes, player performance, and market context. The project intentionally keeps the interface explainable while following the same structure used in modern football analytics pipelines.

Tools, methods, and model stack

  • XGBoost / LightGBM: tree-based ensemble models are well suited to nonlinear transfer valuation because value responds to interaction effects such as age × minutes × output, contract status × form, and position × demand.
  • Feature engineering: the model uses derived signals such as per-90 output, form trend, market momentum, release clauses, contract length, age decay, and club-level scarcity.
  • Validation: standard backtesting with train/validation splits and cross-validation helps guard against overfitting and ensures the model generalises across player profiles.
  • Target definition: the learning target can be market value, expected transfer fee, or a hybrid value metric calibrated from historical sales and scouting reports.
  • Explainability: SHAP values, feature importance ranking, and partial dependence plots can be used to explain why a player is valued above or below the market.
  • Operational workflow: data ingestion, cleaning, feature creation, model training, calibration, and dashboard output are kept in a repeatable pipeline rather than a single static formula.

What is weighted in the model

  • Age: younger players carry more upside and longer value potential, while older profiles see a stronger discount.
  • Minutes played: the more a player is used, the more reliable their recent performance signal becomes.
  • Goals and assists: direct production is a major driver when comparing players of similar profile.
  • Current form: from 0 to 100, the model reflects recent sharpness and consistency.
  • League demand: demand is a proxy for whether a player is seen as scarce or highly valuable in the market.
  • Momentum: positive momentum lifts the value premium while negative momentum compresses it.
  • Contract runway: longer remaining terms usually support a stronger transfer valuation.
